## 浏览目录与未来导入

添加目录弹窗的“浏览”会打开浏览器原生目录选择器，且只从用户选中文件的 webkitRelativePath 提取顶层目录名称；不读取文件内容，不保存子文件清单。

选中后可直接点击保存，将“已选目录”加入样稿；无需强制手填路径。浏览器仍不会提供完整的本机绝对路径，因此条目保存 pathResolved=false、保持未启用且不允许命令确认。列表提供补全路径入口，完成绝对路径表单后才改变样稿启用状态。这仍不是实际目录可访问性或安全授权验证。空目录或不支持 webkitdirectory 的浏览器可能无法返回目录名称，可以直接手填；本页不读取文件内容或枚举系统目录。

读取 Codex / .agent 的 config.toml 导入工作文件夹是后续功能，入口保持禁用；本页不会扫描配置、读凭据或扩大文件授权。

## 真实功能边界

所有连接、目录、授权和备份都只在当前页面内存中，刷新后重置。初始 demo ID / 路径是虚构的；拓扑“就绪 / 在线”是演示状态，不是实际服务观察，ChatGPT 始终未验证。

检查更新不访问更新服务器。健康检测实际检查本页内存数据的空间 ID 唯一性、端口 / 传输参数和授权引用，报告正常或异常；它不探测系统或服务，本机运行时 / Tunnel 单列未接入，不能把页面配置正常读作程序健康通过。备份只保存本页连接、目录和授权配置的副本，恢复需确认，恢复后的连接一律为未连接；不恢复磁盘文件、不持久化、不写 runtime 配置。授权和命令确认不会启动进程、调用后台或更改真实权限。

保留此前字体：中文标题引用本机华文中宋，正文 HarmonyOS Sans SC，英文 Geist，技术值 Geist Mono。三个网页字体仍使用原有网络 CSS，不可用时系统回退；不显示加载状态。
