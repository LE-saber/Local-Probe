## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
| --- | --- | --- | --- |
| 从未跟踪工作树打包 | 第一次实现若枚举未跟踪文件，可能把本机状态带入 ZIP；最终实现已改为只读取 Git index。 | advisory | 新文件先审查并 `git add`，再运行 `Package-LocalProbePreview.ps1`；始终检查 ZIP 中的禁止目录。 |
| Windows 路径分隔符误判 | 打包脚本曾用错误的反斜杠替换表达式，导致合法 `bin` EXE 被判定为禁止路径；已修复并通过 ZIP 内容检查。 | advisory | 修改打包逻辑后必须在 Windows 实际生成 ZIP，并验证 required/forbidden entries。 |
| 把 Cloudflare 与 OpenAI Tunnel 初始化混用 | 初版统一 Setup 曾调用旧的 8787 初始化器，会生成三份无关凭据且工具列表过时；已改为直接生成 8788 Preview 配置。 | advisory | Cloudflare Preview 使用 `Setup-LocalProbePreview.ps1`；OpenAI 8787 只使用独立 Tunnel 文档中的脚本。 |

## Critical Anti-Patterns (do NOT repeat these)

- 不要把 `.runtime`、`.tools`、`.secrets`、`bin`、`dist` 或 `tmp` 加入 Git。
- 不要从整个工作树或未跟踪文件集合生成发布 ZIP；先审查并 stage，再从 Git index 打包。
- 不要把旧 8787 初始化器接回 Cloudflare Preview Setup。
- 不要把本地测试通过写成真实 Cloudflare/ChatGPT、签名、安装器或生产 supervisor 已通过。
- 不要删除归档或 `.secrets`；归档是本轮清理的可恢复路径。
