# Local-Probe 前端交互样品

这是供人工操作验收的单文件 HTML 原型。仅设计与验证前端流程，尚未替换正式 Win32 前端，也未接入真实后端。

## 打开样品

直接用现代浏览器打开同目录的 `index.html`，无需安装依赖，也无需互联网连接。建议通过本机 HTTP 预览，浏览器的本地状态保存行为更一致：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory './prototypes/frontend-preview'
```

然后打开 <http://127.0.0.1:8765/>。只监听本机回环地址。若端口占用，可换一个端口。

样品状态保存在浏览器 `localStorage` 的 `local-probe-preview-v1` 项下，不修改项目配置。设置页的「重置样品」会恢复初始示例数据。不同浏览器和不同 URL 使用独立的样品状态。

## 建议人工验收

1. **外观和导航**：依次打开概览、连接、授权文件夹、活动日志、设置；试用浅色/深色、最大字号及小窗口，评价可读性和操作是否易找。
2. **连接**：正常场景下重连、立即取消、断开后重试；切换 OpenAI / Cloudflare 方案后重新连接。顶部选择「首次配置」，完成两步向导，确认无需输入真实密钥。
3. **错误恢复**：切换「凭据错误」「本机离线」，体验失败重试和明确标注为模拟的修复入口。注意本机就绪与 ChatGPT 工具验收是分开的状态。
4. **授权**：添加示例绝对路径如 `D:\Demo\My-App`，尝试重复路径、相对路径、`..` 和 UNC 路径；搜索、改显示名称、暂停/启用；打开撤销确认，先取消再确认。
5. **日志和设置**：搜索/按类别筛选日志、打开详情、导出 JSON；刷新确认偏好和样品授权保留；用键盘 Tab 和 Escape 操作弹窗。

请直接反馈喜欢或不喜欢的页面、操作卡点、希望调整的布局及用词。「下载反馈记录 JSON」只导出最近模拟事件，不是满意度问卷，也不代表验收通过。只有用户明确认可后，才进入正式前端集成。

## 原型边界

- 原生 HTML/CSS/JavaScript，无第三方库、CDN、网络请求或真实服务连接。
- 不读取真实凭据、文件内容或目录；不要填写真实密钥，样品不提供密钥输入框。
- 添加目录是文本登记，格式检查不是正式路径安全验证；不检测目录存在性、reparse point、磁盘类型或真实权限。
- 文件夹标签修改、暂停开关、连接向导、活动导出和主题设置目前都是原型能力，不表示正式版本已有对应接口。
- 撤销授权只修改浏览器示例列表，不会删除磁盘文件，也不会改变真实后端授权。
- 模拟连接只改变演示状态；「ChatGPT 尚未验收」不会自动改成已验收。错误恢复按钮不修复实际网络或凭据。
- Developer Rules 只读显示；命令执行和文件写入关闭。未来集成不得因为采用此界面而扩大既有安全边界。

## 正式集成对照

| 样品区域 | 现有项目接入方向 | 集成前需确认 |
| --- | --- | --- |
| 概览 / 连接 | `internal/previewui` 的 Connector / 连接进度，`internal/previewconnect` 的真实连接状态 | 配置读取与安全保存、取消/重试语义、真实健康状态、ChatGPT 端验收边界 |
| 授权文件夹 | previewui Workspace Manager 的 List / Add / Remove | 用原有安全路径验证和显式授权；标签/暂停目前不可直接假定后端支持 |
| 活动日志 | 本地诊断/事件来源 | 定义事件模型、查询接口和导出脱敏策略，不能用模拟日志替换真实证据 |
| 设置 / Developer Rules | 本地显示偏好与现有策略状态 | 持久化范围、策略只读展示，不引入任意执行或写入能力 |

正式集成具体使用原生 Win32、WebView 或其他承载方式，需在样品验收后依据项目部署限制决定；本原型未提前引入任何 UI 框架。
