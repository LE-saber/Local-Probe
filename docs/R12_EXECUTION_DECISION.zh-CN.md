# R12-01 执行安全决策

日期：2026-10-23。状态：用户明确选择；实现进行中。

用户在本次开发中明确允许新增“受信任主机执行”模式，已知其使用当前用户实际的文件与网络权限，不承诺沙箱隔离。因此新增独立 `execution_policy=trusted_host`。不再将严格网络 enforcement 作为该模式的准入条件，也不更改系统网络策略。

`isolated_required` 保持原门禁，作为所有旧连接的默认策略。新增策略不等于授权：开发者开启、连接范围、具体操作审批、版本/身份绑定、资源限制与撤销仍是必要条件。默认配置不会自动启用命令或写入。

命令运行器继承当前用户 OS 权限，路径规则无法限制其自行读取/修改其他文件或访问网络。该事实必须在本地授权界面中明确显示，不能只标注“高级”。

实现优先复用已有 Windows suspended launch、映像身份校验、Job Object 和有界输出；固定版本探针继续保持其原有限制。受信任执行独立入口支持受批准的子进程树，不把原有固定探针放宽成任意命令。

配对、Relay、工具调用与执行策略仍须按阶段完成，不以这项决策声称已经实现远程执行。
